Как это работает

📊

Индикатор в углу экрана

Показывает процент заполнения контекстного окна от лимита в реальном времени.

🔄

Автоматический сбор истории

История диалога подтягивается автоматически из сети, без прокрутки чата.

⚡

Обновление в реальном времени

Процент и цвет индикатора обновляются с каждым новым сообщением в диалоге.

🧠

Автоопределение модели

Модель определяется автоматически по данным сайта — не нужно настраивать вручную.

Установка

  1. Скачайте и распакуйте архив с расширением в любую папку на компьютере.
  2. Откройте chrome://extensions в адресной строке браузера.
  3. Включите «Режим разработчика» (переключатель в правом верхнем углу).
  4. Нажмите «Загрузить распакованное расширение».
  5. Выберите распакованную папку с расширением и подтвердите.

Скриншоты

Google AI Search: зелёная зона и окно расширения
ChatGPT: красная зона (больше 80%)
Gemini: жёлтая зона (больше 50%)
Claude: история подгружается сразу при открытии чата, модель определяется из сети (Sonnet / Opus / Haiku, окно 200 000 токенов)
Perplexity: перехват истории треда и потока ответа, поддержка Sonar / Sonar Pro и сторонних моделей
