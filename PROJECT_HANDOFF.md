### Конвенции

**Кодер:** DSH Desktop (DeepSeek Harness), workspace `ai-context-monitor-clean`  
**Модель:** deepseek-flash  
**Промпт кодеру:** режим act; контекст-перенос ≤3 строк; задача пунктами; список «не трогать»; ответ = diff + отчёт ≤10 строк  
**Сессии:** новая сессия для каждой задачи

**Усилие рассуждений:** обязательный параметр в каждом промпте для DSH.  
- **Max** — архитектурные задачи (рефакторинг, декомпозиция, миграции)  
- **Medium** — фиксы (O-9-подпись, O-11, O-19)  
- **Low** — косметика (O-14, комментарии)  
- **Формат:** первая строка промпта, перед `Режим: act`

**Тарификация DSH:** peak/off-peak (пик Пекин 09:00–12:00 и 14:00–18:00 = Екб 06:00–09:00 и 11:00–15:00; тяжёлые прогоны — вне пика)

## Конвенции процесса

Правила, выработанные в цикле O-15…O-20:

1. **Два провала фикса одного симптома → следующий промпт только измерение.** Если симптом воспроизводится после второй итерации, следующая сессия заказывает измерение без правок.
2. **Каждое утверждение с основанием.** Все утверждения помечены: «лог строки N», «скриншот», «гипотеза, не проверено».
3. **Критерий приёмки привязан ко времени.** «Снимки в пределах одной секунды» или «одновременно».
4. **Харнесс ≠ приёмка live-багов.** Приёмка = живое побайтовое равенство на захваченном payload в реальном браузере.
